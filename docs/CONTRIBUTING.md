# Contributing

Read [AGENTS.md](../AGENTS.md), [current status](STATUS.md), and
[development](DEVELOPMENT.md) first. This is a preserved personal project with no
committed feature expansion roadmap.

Keep changes focused, preserve unrelated work, and verify the actual registered
command path. Use synthetic commands and disposable application data for tests.
Document observed behavior and verification limits. Update the existing owning
document rather than adding a new planning or completion report.

Historical contributor instructions are available in [archive](archive/README.md).
